# TIP — Tracker Inventory Project 📦

A fully coded file-management system written in **C** that tracks item quantities and prices using text-file-based persistence. Originally submitted as a course project for **CMSC 21**.

---

## 📋 Features

- Display, add, modify, and remove products
- Input sales and update existing product quantities
- Record and print all transactions
- Generate a full **General Ledger**
- Generate **Financial Statements** and close nominal accounts
- All data persisted via `.txt` file reading and writing

---

## 🛠 Tech Stack

| Layer | Technology |
|-------|-----------|
| Language | C |
| Storage | Text file I/O |
| Data Structures | Linked lists / structs |
| UI | Terminal / CLI with ASCII art |

---

## 🚀 Running the Project

1. Make sure you have a C compiler (GCC recommended):
   ```bash
   gcc main.c -o tip
   ./tip
   ```
2. Ensure `products.txt` and other data files are in the **same directory** as the executable.

> **Note:** This project was originally submitted via Google Drive and was not version-controlled on GitHub at the time of development. The repo was created afterward to preserve and share the work.
